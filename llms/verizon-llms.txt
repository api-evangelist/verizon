# Verizon

> Verizon Communications is a US telecommunications carrier whose developer surface spans three
> distinct properties: ThingSpace (IoT connectivity management, device diagnostics, location,
> software management), the developers.verizon.com API Marketplace (TM Forum-aligned service
> management, private IP and secure cloud interconnect APIs for enterprise network customers), and
> the 5G Edge portal (mobile edge compute discovery). Access is enterprise-contracted; there is no
> public self-serve pricing. Verizon publishes no OpenAPI, no AsyncAPI, no /.well-known/ discovery
> document, no MCP server and no agent card. It does publish a rich webhook (callback) catalogue,
> a detailed error-code registry and a two-token OAuth model.

Generated by API Evangelist on 2026-08-04 from https://github.com/api-evangelist/verizon.
Verizon does not publish an llms.txt of its own: https://developers.verizon.com/llms.txt returns
HTTP 200 with the React SPA shell (an unmatched-path catch-all), not an llms.txt document.

## APIs

- [Verizon ThingSpace Connectivity Management](https://thingspace.verizon.com/documentation/apis/connectivity-management.html): Activate, deactivate, list and message IoT devices. Base URL https://thingspace.verizon.com/api/m2m/v2
- [Verizon Accounts API](https://thingspace.verizon.com/documentation): Account information, features, carrier information and IP pools
- [Verizon Devices API](https://thingspace.verizon.com/documentation): Device listing, activation and deactivation
- [Verizon SMS API](https://thingspace.verizon.com/documentation): Machine-to-machine SMS to and from devices
- [Verizon Session API](https://thingspace.verizon.com/documentation): Connectivity Management session login, issuing the VZ-M2M token
- [Verizon Callbacks API](https://thingspace.verizon.com/documentation): Register and list callback listeners
- [Verizon 5G Edge](https://www.verizon.com/business/solutions/5g/edge-computing/): Mobile edge compute and edge discovery service
- [Verizon Service Management APIs](https://developers.verizon.com/#/apis/ns/products/service-management-apis/dep-inventory-management-tmf): TM Forum-aligned Inventory, Incident, Change, Event, Problem, Order and Billing Management
- [Verizon Dynamic Network Manager](https://developers.verizon.com/#/apis/ns/products/private-ip-apis/dynamic-network-manager-mef-1): MEF-aligned private IP bandwidth management
- [Secure Cloud Interconnect APIs](https://developers.verizon.com/#/apis/ns/products/secure-cloud-interconnect-apis/SCI-Utilization-API): Utilization and billing usage

## Runtime semantics

- [Authentication](https://raw.githubusercontent.com/api-evangelist/verizon/refs/heads/main/authentication/verizon-authentication.yml): Two-token model — OAuth 2.0 client credentials (1 hour) plus a VZ-M2M session token (20 minute idle timeout)
- [OAuth scopes](https://raw.githubusercontent.com/api-evangelist/verizon/refs/heads/main/scopes/verizon-scopes.yml)
- [Conventions](https://raw.githubusercontent.com/api-evangelist/verizon/refs/heads/main/conventions/verizon-conventions.yml): Asynchronous request/callback pattern; no idempotency key; no pagination
- [Error codes](https://raw.githubusercontent.com/api-evangelist/verizon/refs/heads/main/errors/verizon-error-codes.yml): Namespaced ServiceName.CLASS.Specific codes; INPUT_INVALID / REQUEST_FAILED / REQUEST_ONHOLD / REQUEST_CANCELLED
- [Webhooks / callbacks](https://raw.githubusercontent.com/api-evangelist/verizon/refs/heads/main/asyncapi/verizon-thingspace-callbacks-webhooks.yml): 14 callback services across three message categories
- [Lifecycle](https://raw.githubusercontent.com/api-evangelist/verizon/refs/heads/main/lifecycle/verizon-lifecycle.yml): URI-path versioning at v2; no deprecation policy; no API status page
- [Changelog](https://raw.githubusercontent.com/api-evangelist/verizon/refs/heads/main/changelog/verizon-changelog.yml)
- [Data model](https://raw.githubusercontent.com/api-evangelist/verizon/refs/heads/main/data-model/verizon-data-model.yml)
- [Rate limits](https://raw.githubusercontent.com/api-evangelist/verizon/refs/heads/main/rate-limits/verizon-rate-limits.yml): Negotiated per contract; 429 with Retry-After
- [Sandbox](https://raw.githubusercontent.com/api-evangelist/verizon/refs/heads/main/sandbox/verizon-sandbox.yml): API Console with a simulator back end
